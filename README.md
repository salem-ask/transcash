# TransCash — branche de publication Hostinger

Cette branche contient uniquement l'application **construite** (`npm run build`), servie telle quelle par
Hostinger (transcash.bookline.digital). Ne pas modifier à la main : elle est régénérée depuis la branche
de développement. Aucun secret ici : les identifiants de la base sont saisis sur l'écran d'installation et
enregistrés sur le serveur, hors du dossier public.
